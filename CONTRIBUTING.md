# Como contribuir

Que bom te ver por aqui. Na House de Criatividade a gente cria junto: *creative minds for the kingdom*.

## Antes de começar

1. Atualize a `main` e crie a sua branch a partir dela.
2. Mantenha o pull request pequeno: uma mudança, um assunto.
3. Escreva mensagens de commit claras, no imperativo, dizendo o que mudou e por quê.

```bash
git checkout main
git pull
git checkout -b sua-branch
```

## Abrindo o pull request

- Descreva o que mudou e como testar.
- Peça revisão. Ninguém faz merge do próprio trabalho sem um segundo olhar.
- Não faça push direto na `main`. Toda mudança entra por pull request.

Dúvida no meio do caminho? Chame alguém da House. Servir bem também é perguntar cedo.
